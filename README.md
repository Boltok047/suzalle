# Suzalle

Een Nederlandstalige storefront-demo voor de sieradencollectie van Suzalle, gebouwd met HTML, CSS en vanilla JavaScript.

## Getting started

No package installation or build step is required. Serve this directory with a local web server, for example:

```sh
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Prototype scope

- Responsive storefront with collection browsing, search, filtering, and sorting.
- Client-side favorites and a shopping cart with quantity controls.
- Productfoto's worden lokaal geladen uit `public/images/`.
- De collectie is een kleine demoselectie; controleer productnamen, prijzen en beschikbaarheid voordat deze storefront live gaat.
- De winkelwagen is alleen een frontend-demo. Afrekenen, voorraad, betalingen en orderverwerking zijn niet aangesloten.
